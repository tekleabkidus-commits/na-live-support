The Copilot panel

B8-S01-copilot-panel-v2 · Section A · checklist rows A01–A16 (+ X1 designed absence) · Doc 09 FR-14, FR-16, EC-09, FS-01, §8, §9, §13, §14 · BR-01/AC-06 · v2 — scope-limited reopen (closing-audit ruling, 27 Aug): ADDS the post-discard resting frame in §A; nothing else changed

This panel earns its place only if an agent trusts it in the worst minute of a shift — an angry withdrawal thread, forty messages deep. So every section says where its content came from and how fresh it is, the draft card never pretends confidence it doesn't have, and the one thing the panel can never do is send: Insert puts text into the composer and stops — sending stays the agent's act (BR-01, designed absence X1: no send affordance exists anywhere on this surface).

The frame is not mine: the 380px context panel, the Ticket / Customer / Copilot tab order and treatment are B1-S01-v2 law, shown for context only. Everything inside the Copilot tab is this screen's subject. Components and the AI accent are B1-DS verbatim — every AI-authored artifact carries the violet family plus a text label, never color alone. Amharic is real text, flagged for native review.

§A — The panel, fully populated · 1440 · light
A01 A02 A03 A04 A05 A06 A09 A10 A11 A12 A13 · FR-14 · §9 confidence as text · guardrail WITH the card (standing ruling)
Reading order is decision order: what is this thread (summary) → what does the AI think it is (chips) → what could I say (draft) → what backs it up (KB, similar, macros). The guardrail strip is glued to the draft card it warns about — an amber note at panel level would read as ambient noise and get banner-blind in a week. Confidence is five segments and "82% · High": the §9 never-color-alone rule, applied to the meter itself.

§H — Accessibility & motion contract (build notes on the frame)
A15 · §13 · §9 streaming rules
Contract
· Every section is role="region" with an aria-label; streamed draft updates announce politely at sentence boundaries, never per token.
· Confidence is always text ("82% · High") beside the segments — the meter is decoration, the words are the meaning.
· Insert / Regenerate / Discard are fully keyboard-operable; after Insert, focus moves to the composer textarea (Doc 09 §13).
· Reduced motion: streaming renders in chunks, the caret does not blink, nothing pulses; skeletons are static blocks.
· Both themes hold WCAG AA on every text/background pair used above (the violet family on its own surfaces included).
· Designed absence X1, audited here: no send control exists on this surface, in any state, at any viewport — the composer's send is the only send (BR-01/AC-06).
