B6-S14-translation-manager-v1 rows N01–N13

Translation manager & language administration

Ten thousand keys, and the only ones that matter today are the fourteen an Amharic-speaking player hit this week. So the manager opens on missing-first, ordered by what customers actually ran into — telemetry, not the alphabet. An alphabetical wall is a filing cabinet; this is a worklist.

Two classes of string share one table and must never blend: platform strings that ship with the code and get overridden, and operator content that the tenant wrote in the first place. Overriding “Send” is a cosmetic decision; editing the responsible-gaming template is a regulated one. They carry different chips, different provenance and, for the RG template, a different permission.

The manager's own interface is never edited by the manager — a meta-level separation drawn explicitly in §C. Components are B1-DS verbatim; the shell is B6-S11's.

Why this order

These fourteen keys are the ones Amharic-speaking customers actually reached this week — 1,545 times between them. The other 9,827 keys are either translated or nobody has hit them. Fixing the top three covers two thirds of the exposure.

A missing string is never blank

It falls back down the chain — አማርኛ, then English — so a player sees English rather than an empty label. That is why these are gaps, not outages.
