B6-S05-bot-templates-commands-v1 rows E07–E11

Bot messages & commands

Six named templates and five fixed commands — the words a player actually reads. Two rules shape the screen. First, the shipped wording is always visible beside the operator's version, so an edit is a comparison rather than a leap of faith, and reset is one press away. Second, the preview is a real message bubble, not a text box — because these strings are judged as messages, and a variable that reads fine in a form can read strangely in a chat.

Bubbles, modified badges, tables and buttons are B1-DS verbatim; the shell is B6-S01's; the language tabs and completeness badges are the ones approved on B6-S04.

Amharic is real text, flagged for native review before i18n keys freeze.
