Every state on this page is a status the system reports about itself; the only actions here are config changes — versioned, instant, reversible — never deploys.

Credentials appear exclusively as vault references. The Backoffice shell is B6-S11 law — context only. Provider names are the platform's real suppliers; models are fixture ids.
