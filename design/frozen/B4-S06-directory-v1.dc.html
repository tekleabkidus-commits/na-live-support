The directory

Checklist rows G01–G09 · Doc 08 FR-20, EC-08, FS-01, BR-03, §8, §9, §14 · AC-07. The list an agent reaches for when the conversation is not already open — usually because someone has phoned, or because they are checking whether two profiles are the same person. The table is B1-DS's data table with the columns Doc 08 names.

Two constraints shape it. Search has to find people by things they no longer are — an old username, a phone they gave once — because that is what a returning player has. And the RG filter must not exist for staff who cannot see the flag: a filter that returns fewer rows is itself a disclosure.
