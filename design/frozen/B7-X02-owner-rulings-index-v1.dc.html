Owner rulings index

Every decision the owner made that no specification document contains. Each began as a silence or a conflict, was ruled on explicitly, and now binds the build exactly as a document clause does — with the difference that a developer reading Docs 01–18 will never encounter it. That is what this file is for.

Scope caveat, stated because the index is only useful if its limits are known: this covers rulings recoverable from the Batch 7 design record. Rulings made in Batches 1–6 are cited where a Batch 7 decision depends on them, but their own full record lives in those batches' audits — I have not reconstructed from memory what I cannot quote.

How to use this in the build

Treat each entry as a clause with the same force as the document it sits beside. Where an entry conflicts with a reading of a document, the entry is the narrower and later statement and governs — that is what makes it a ruling rather than a preference. Where an entry is silent, the document governs, and a new silence is a question for the owner, never an opening for invention. Two entries carry conditions that outlive this batch and should be read before any theme or i18n work: R-09 on the token colourways and R-14 on the Amharic review's standing.
