Version history & rollback

Doc 16's success scenario for this screen is fifteen minutes and two audit rows: something looks wrong after a publish, somebody puts it back, and the record shows both events. So the design goal is that an operator under pressure can tell which version they want by looking — before-and-after thumbnails per surface, not a diff of token names.

The rule that makes this section and Section S one system: a rollback is a publish. Same validators, same no-override wall, same four-eyes where the tenant has it on. A past version whose contrast now fails is blocked by the same dialog — because history cannot be a tunnel under BR-02's wall.

Built on B1-DS v4, and on the standing rule adopted at Section S: status hues stay with their semantic components; generic pass/fail uses neutral tokens.

§A

The history, and what actually changed

T01 · T02 · Doc 16 FR-03, T-01, AC-02, §8

Newest first, the live one marked, every row carrying who published it and when. Selecting a version puts its surfaces beside the live ones — the sign-in card, the app chrome, an email — so the question “is this the version with the gold buttons?” is answered by the thumbnails rather than by a changelog. History is append-only in presentation: a version is never edited, only superseded, and a rollback adds a row rather than removing one.

§B

A rollback is a publish

T03 · T04 · Doc 16 FR-03, BR-02, EC-02, AC-02

The confirmation is Section S's dialog with a different heading, and it names both ends of the move — what you are leaving and what you are returning to — because someone rolling back at speed needs to be sure they are not undoing the wrong publish. Two ways it can be refused, and both are the point: a version whose asset has since been deleted, and a version whose contrast no longer passes.

That second one deserves saying plainly: a theme that was publishable in May can fail today, because the tokens it was validated against have moved. Letting it through because it is “only a rollback” would be the one tunnel under BR-02's wall — so history is not an override channel, and the dialog that stops it is the same dialog.
