Composer AI actions

B8-S02-composer-actions-v1 · Section B · checklist rows B01–B08 (+ X1, X4 audited) · Doc 09 FR-15, FR-16, US-04, EC-10, §8, §13, §14

Four verbs live in the composer's AI slot: Draft · Improve · Translate · Summarize. Each produces a card the agent reads before anything moves — and every card ends the same way: text lands in the composer, the send button stays untouched, unclicked, the agent's own. The dangerous verb here is Translate, because translation can silently change money; so the two-line preview is mandatory before send, the original is stored and hoverable forever after, and a translation that alters a digit is blocked, not warned.

The composer chrome (modes, textarea, send) is Doc 07 law — context only. The AI slot's placement in the action bar is Doc 07 FR-19's; what fills it is this screen's subject. Components and the violet family are B1-DS verbatim; every AI product carries the text label. Amharic is real, flagged for native review.

§C — Translate · 1440 · light
B04 B05 B06 · FR-15 · US-04 · EC-10 · §14 digit validator — the money-safety rule
An agent who cannot read the output language is signing something they cannot check — so the design gives them the two things they can check: the preview pairs every line with its original, and the validator guarantees the numbers are untouched. When it can't guarantee that, the send path closes. Not a warning — closed.

§G — Accessibility & honesty contract (build notes on the frame)
B08 · §13 · X1 X4 audited · FR-16
Contract
· Every card is a labeled region; keyboard reaches all verbs and card actions; Insert returns focus to the textarea (§13).
· The preview pair reads as two labeled lines (EN/AM) — comprehensible to a screen reader, not a visual diff only.
· The validator's block names the digits it caught, as text; the blocked state has no color-only signal.
· X1 audited: every card action is Insert / Edit / Discard — no card sends. The send/Add-note button is the composer's own, untouched by this slot.
· X4 audited: every drafted money sentence claim-frames or states the process, never a fact about the customer's account balance.
· Every use is logged with its outcome — inserted unedited, inserted edited, discarded (FR-16); the ✦ markers on inserted text are what make that trail visible to staff.
