07 · Account state chip — proposed as a B1-DS addition
Four states, each icon plus word, never colour alone: Active reuses the presence pill from the B1-DS top bar verbatim (green dot on a hairline pill); Invited takes the info surface #EDEEF2/#D5D8DE/#4A5460; Locked the warning surface; Disabled the neutral #EEECE6 on #DCD8CF.
No new hue enters the system, and deliberately none of the fixed ticket-status, priority or SLA hues are reused — an account state is a different vocabulary and must not read as a ticket state.
What I did not add, though it was tempting
No last-sign-in column, no department, no filter chips, no per-row menu, no CSV export, no bulk disable. Each would have been defensible and none was authorised — your ruling said four columns, a search, and rows that open the profile. The list is deliberately the least interesting screen in the batch.
