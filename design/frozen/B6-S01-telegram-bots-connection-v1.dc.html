Telegram — bot registry & connection method

The shell every later Telegram screen hangs off. Nothing here restyles an approved element: surfaces, borders, type scale, buttons, tables, skeletons, toasts, connection-state pills and channel-health tokens are lifted from B1-DS verbatim, and the top bar is B1-S01's chrome unchanged.

Two decisions worth your eye. First, the token is a one-way door: it is accepted, validated, and then never rendered again — so the field's own copy has to teach that, or an admin will hunt for a reveal button that does not exist. Second, changing the connection method never disconnects anything, and the confirmation says so in its first line rather than making an admin infer it from a scary red dialog.

Amharic here is real text and is flagged for native review before i18n keys freeze. Data is NA BET PLC's: real-shaped bot usernames, real support-account names, Ethiopian staff names.
