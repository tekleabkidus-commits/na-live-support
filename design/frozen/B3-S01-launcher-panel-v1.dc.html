Launcher and panel shell

Checklist rows B01–B10 · Doc 13 §8, §9, NFR-01, BR-01. The frame every other screen lives inside. 375 leads: below 480px the panel is a full-screen sheet, not a shrunken card. Everything is drawn in the neutral default — the launcher colour, icon, corner, offsets, font and avatar are all operator configuration, and the Widget Designer is where they change. In-panel type is 15px per §9, larger than the agent app, because this is read once by a stranger rather than all day by a professional.

B10 · What the host page gives up

Doc 13 NFR-01, BR-01 · FR-24

Nothing. Two fixed-position iframes and a namespaced global — no styles injected, no layout reflowed, no DOM read. It is worth drawing this as a rule rather than a diagram: the widget's whole security and safety model is that it cannot touch the page it sits on, and every feature request that would need host-DOM access is refused by the architecture rather than by policy.
