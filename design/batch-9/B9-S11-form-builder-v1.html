Baseline: the built resources/js/Pages/Workflow/FormBuilder.vue (palette / canvas with step tabs and placement buttons / inspector with per-language labels and completeness, required-when-visible, the conditional with its plain-sentence render; the dual preview from the server’s contract renderers; the publish dialog with FR-22 blocks and the usage banner; the version history with a fields diff; the ≥1024 notice) and Forms.vue, refined. Differs from build: (1) drag placement drawn as the enhancement WITH the built placement menu and ↑↓ buttons as the requirement (checklist divergence 3); (2) the widget preview is B3-S05’s pre-chat anatomy and the Telegram preview is the device-styled frame with BOTH modes side by side (the build prints label lists and a plain transcript); (3) the inspector shows the EC-08 note when a condition points at a removed option; (4) the publish dialog lists every FR-22 block with its code, a jump link and the EC-07 auto-fix; (5) the version history draws per-version added / removed / changed lines; (6) the forms list carries the seeded tag, usage and submission counts.

Designed absences: no edit affordance on any published version — diffs only (BR-06, X5); no forward reference — the condition picker never offers a later field (FR-20); no free-text or script in a definition — the field set is the 13 closed types (SEC-04); no “verified” anywhere on a customer form; no form can bypass the transition service — completion actions are tag · route · priority through the doors (BR-02); nothing by colour alone — dots carry tooltips, the branch glyph carries its sentence.
