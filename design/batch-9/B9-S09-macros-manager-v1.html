Baseline: the built resources/js/Pages/Workflow/Macros.vue (grouped by scope with usage counts and kind, the editor with a variable palette, pills, bundled-action checkboxes, LIVE PREVIEW through PaletteReader::preview — the one resolver; no send door on the page), refined. Differs from build: (1) the body is a pill editor — brace-free pills with uneditable inner text and delete-as-unit (B12-S03’s ruling, §9) — where the build is a textarea holding the double-brace form with a pill strip beneath; (2) LANGUAGE VARIANTS per macro with completeness dots (I05; B12-S03 assigns them to Doc 12 — checklist divergence 4) where the build has one body; (3) bundled actions are chips carrying their value, where the build has three checkboxes; (4) the preview renders the resolved values inline (B12-S03’s highlight) and the missing case as the warning pill plus the T-06 line, where the build prints text and an unresolved list; (5) the list carries the kind tag, bundled chips and language dots per row.

Designed absences: no send anywhere on this page (X3, B12-S03: insertion never sends); no way to type a variable as raw text — the pill is the single notation; the missing-variable warning is never suppressible; no scope change after creation (the build’s rule); no “verified” anywhere; bundled actions never borrow privilege (EC-09); nothing by colour alone — the missing pill carries ⚠ and its words.
