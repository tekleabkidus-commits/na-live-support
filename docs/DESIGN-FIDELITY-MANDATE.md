## §3 — DEVIATIONS: EXACTLY THREE CLASSES, ALL FILED, NONE SILENT

Class 1 — technical necessity or document conflict (the document wins; both
citations). Class 2 — design gap (fill from design-system components only, nearest
drawn pattern, owner ruling naming the fill). Class 3 — design defect (flag, wait,
build nothing). A conflict or gap is a MANDATORY batch stop. Stale frame references
are STRUCK. First real implementation of a never-rendered drawn state is a
FRAME-MAPPING row, not a deviation. **A whole-document design gap is NOT a flood of
class-2 rows: the Option A precedent governs (R-D09-2, reaffirmed as R-D10-3) —
backend-first build, a parallel design batch if the owner orders one, functional
screens riding a [B-batch] bucket until freeze.** Doc 10 proved the shape twice over:
its surfaces shipped functional, themed, i18n-keyed, axe-clean and browser-proven,
with pixel fidelity deferred to [B9] — and an unlinked screen was ruled a worse
deviation than adding one nav row.
