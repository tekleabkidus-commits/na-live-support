## 1. The frozen record is the specification
`design/frozen/` — ls-verify the count yourself (204 at 00e2473; never
inherit a number). The design SYSTEM binds every build: `B1-DS-design-
system-v2` §2 (both colourways) + addenda B5, B6 (v3), B7 (v4), the AI
anatomy tokens from F1, and the WARN token usage established at S13 (a
"busy" band recolours the dot to WARN, never a number, never the success
green). Re-run the committed hex-extraction script before any first screen;
tokens only, never literals; undefined token names are defects even when
the render "looks right." The platform's ContrastValidator (A-62, shared
kernel) refuses failing combinations with suggested corrections and has no
override — any surface that lets an operator pick colours consumes it.

## 2. Fidelity: 100%, per frame
Every frame, state, viewport, theme, and language of a frozen file that maps
to a built surface. FRAME-MAPPING ROWS are mandatory: enumerate the frames
from the frozen files themselves and map each to its implementation + proof.
Proofs assert VISIBILITY, not existence. **A frame row reads PROVEN only when
an executed test asserts the drawn behaviour; BUILT-not-asserted is stated,
never counted, and is not left unbucketed at a close** (the S13 recount
addendum: five "BUILT" rows became executed legs and found defects). A
per-frame caption is an instruction.

## 3. Deviations: exactly three classes, every one filed
1. Document conflict — the spec document wins; both citations filed (D13-D08:
   a drawn tombstone the platform's read contract cannot serve).
2. Class-2 fill — a state the document requires that no frame draws; filled
   from the NEAREST drawn pattern; owner-ruled at a mandatory stop.
3. Technical necessity — filed with the mechanism; design DEFECTS (drawn
   figures the formula does not produce — D13-D07) are class 3, owner-ruled,
   the frozen file untouched.
Stale frame references are STRUCK. Already-filed deviations are CITED, never
re-filed. A whole-document gap is Option A (R-D09-2/R-D10-3/R-D12-2), never
a class-2 flood.
